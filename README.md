# PD3 Study Studio

A study app for the Danish exam **Prøve i Dansk 3 (PD3)**: flashcards, expressions, grammar lessons, reading lessons, practice questions, and writing and speaking practice.

**Open the app:** https://evanpall.github.io/pd3-study-studio/

- Works on phones and laptops; nothing to install. On Android you can use the browser menu → *Add to Home screen*.
- Progress is saved in your own browser only. Each browser or device keeps its own record. Use *Settings → Export progress* to save or move it.
- Dark mode follows your device setting.
- Exercises marked "PD3-style" are newly written practice, not official exam questions. Official papers are linked from [danskogproever.dk](https://danskogproever.dk/).
